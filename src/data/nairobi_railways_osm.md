# Nairobi railway geometry

This asset is a filtered extract from the HOTOSM **Railways of Kenya** GeoJSON export, sourced from OpenStreetMap contributors. It is used as map context and must retain OpenStreetMap attribution in the product. The source dataset is available under the Open Database License (ODbL): https://data.humdata.org/dataset/hotosm_ken_railways

The extract is not a guarantee of current passenger service, operating status or timetable accuracy. Kenya Railways timetable information should be checked separately before displaying live departures.
