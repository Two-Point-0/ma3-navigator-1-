MA3 SIGHT POSTERS: one picture per sight

HOW TO USE
1. Paste one prompt below into your image AI (or use it as a Canva / Figma brief). Make a landscape picture, 1200 x 800 pixels, JPG, under 300 KB.
2. Save it with the exact file name shown.
3. Put all files in the project folder: public/sights/
4. Run: git add .  then git commit  then git push origin main. Vercel updates the site.
Gates and entrances use their park's picture, so you do not need extra pictures for them.
If a file is missing, the poster shows a blue background with the sight's icon.

RULES FOR EVERY PICTURE
- No text, no logos, no brand names, no recognisable faces. This keeps copyright safe.
- Landscape 3:2. The bottom 35% should be calm (the title sits there).
- Make your own original image. Do not copy a photographer's photo.
